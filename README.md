Тут представлены выполненные 12 лабораторных работ на разные темы по web-программированию
На основе JS/HTML/CSS, серверной части nginx и БД PostgreSQL(вдминистрирование через sql-запросы и adminer), так же они контейнеризированны через Docker для легкого развертывания на любом устройстве
Первая часть заданий идут как статическая страница сайта, без использования БД или запросов на "сервер"
Вторая же часть написана с помощью фрейма Node.js и имеет как работы с БД, так и работу с серверными запросами
